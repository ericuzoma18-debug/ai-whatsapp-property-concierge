# AI WhatsApp Property Concierge

An AI-powered WhatsApp Property Concierge built for real estate businesses to automate property enquiries, recommendations, lead qualification, lead capture, and sales-team notifications.

## Project Overview

This project demonstrates how AI and workflow automation can streamline the journey from a customer's WhatsApp enquiry to a qualified lead for the sales team.

The system understands the customer's property requirements, searches a property database, generates suitable recommendations, scores the lead, captures the enquiry, and notifies the sales team.

## How It Works

1. Customer sends a WhatsApp enquiry
2. Customer requirements are extracted
3. Lead is scored based on buying intent
4. Property database is searched
5. AI generates a response
6. Lead is captured in Google Sheets
7. Sales team receives an email notification

## Key Features

- WhatsApp property enquiries
- AI extraction of customer requirements
- Property database search
- AI-powered property recommendations
- Lead scoring and qualification
- Automated lead capture
- Sales-team email notifications

## Technologies Used

- n8n
- WhatsApp Cloud API
- Google Gemini
- Google Sheets
- Gmail
- JavaScript

## Business Problem

Real estate teams often receive enquiries through messaging platforms and manually collect customer requirements, search available properties, qualify leads, and notify sales representatives.

This automation reduces that manual process and creates a structured workflow for handling property enquiries.

## Project Outcome

The workflow connects customer communication, AI processing, property data, lead qualification, and sales notification into one automated system.

## Future Improvements

- Automated inspection booking

- Lead follow-up automation
- Property image delivery through WhatsApp
- Conversation memory for returning customers
- Sales dashboard and analytics

## Disclaimer

This project is a portfolio demonstration built to showcase AI automation and workflow design. It uses sample property data for demonstration purposes and is not presented as a production deployment.
